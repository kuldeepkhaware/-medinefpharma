# MediNef Pharma

MediNef Pharma is a modern pharmaceutical website developed to showcase pharmaceutical products, healthcare solutions, and company information.

## About

MediNef Pharma provides information about pharmaceutical products, healthcare services, manufacturing capabilities, quality standards, certifications, and research & development.

## Features

- Pharmaceutical Products
- Product Categories
- Product Details
- About Us
- Manufacturing
- Quality & Certifications
- Research & Development
- Facilities
- Gallery
- Careers
- News & Updates
- Contact Us
- Responsive Design
- Admin Panel
- PHP & MySQL Integration

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- AJAX
